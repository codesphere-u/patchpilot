Questions teams ask first

Why build an AST guard when CI runs tests anyway?

Autonomous coding agents often make CI pass by deleting failing assertions, decorating tests with @pytest.mark.skip, wrapping errors in except Exception: pass, or editing test helpers. CI reports green even though the bug remains. PatchIntegrityGuard rejects those diffs at AST parse time in 0.101 ms p50.

How does PatchPilot reduce token consumption without missing helper bugs?

A bug inside a 1-hop callee often surfaces in a caller frame. FaultLocalizer weights traceback frames alongside bidirectional AST call-graph edges and BM25 error tokens, packing only the minimal line-numbered function slices into your target budget.

Is apply_transactional_patch exposed on the public Vercel endpoint?

No. For safety, api/index.py puts apply_transactional_patch in HOSTED_BLOCKED_TOOLS and rejects workspace_root arguments on public HTTP requests. Run patchpilot serve-stdio locally for snapshot mutations.
